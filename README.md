# Mark Alexis Batis - Portfolio

Welcome to the repository of my personal portfolio website! This project showcases my journey as a Software Developer, my professional experience, projects, and my vision for creating beautiful, functional digital experiences.

## 🚀 Overview

This is a modern, highly interactive, and performant web application built to serve as my digital presence. It features smooth scrolling, dynamic scroll-based animations, and a clean, minimalist aesthetic with a focus on typography and whitespace.

## 🛠️ Tech Stack

This portfolio leverages a powerful modern frontend stack:

*   **Framework:** [Next.js (v16)](https://nextjs.org/) & [React (v19)](https://react.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS (v4)](https://tailwindcss.com/)
*   **Animations:** 
    *   [Framer Motion](https://www.framer.com/motion/) for React-based declarative and scroll animations.
    *   [GSAP](https://gsap.com/) for complex, high-performance web animations.
*   **Scroll Experience:** [Lenis](https://lenis.studiofreight.com/) for fluid smooth scrolling.
*   **3D Elements:** [Three.js](https://threejs.org/) for immersive 3D graphics.
*   **Theming:** `next-themes` for seamless light/dark mode support.
*   **Icons:** `lucide-react`

## 📂 Project Structure

The core sections of the portfolio are built as modular React components under `src/components`:

*   **Hero:** A dynamic landing section with parallax scroll effects and a marquee background.
*   **About:** My story, background in Computer Science, and vision as a developer.
*   **Experience:** A timeline of my professional work history.
*   **Projects:** A showcase of my featured work and technical achievements.
*   **Skills:** A breakdown of my technical expertise and leadership philosophy.
*   **Contact:** A form to get in touch for collaborations.

## 💻 Getting Started

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   *or if you use yarn/pnpm:*
   ```bash
   yarn install
   # or
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.
